# Andrei Doca - UI/UX Designer Portfolio

## Vanilla HTML, CSS, JavaScript Portfolio Website

This is a clean, modern portfolio website built with vanilla web technologies:

- **index.html** - Main HTML structure
- **styles.css** - All CSS styling with Work Sans font
- **script.js** - Interactive functionality

## Features

- Responsive design
- Work Sans typography
- Interactive buttons with hover effects
- Smooth animations
- Placeholder for profile image (396x396px recommended)
- Mobile-first approach

## Setup

1. Open `index.html` in your web browser
2. Add your profile image to replace the placeholder
3. Customize content as needed

## Image Placeholder

Replace the placeholder in the hero section with your own image:
- Recommended size: 396x396px
- Format: JPG or PNG
- Update the image path in the HTML or CSS as needed

## Browser Support

Works in all modern browsers with CSS Grid and Flexbox support.
