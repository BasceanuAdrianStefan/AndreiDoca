# Proiect Vanilla HTML/CSS/JS - Andrei Doca Portfolio

## Fișiere pentru proiectul final:

### Fișiere principale (ACESTEA SUNT CELE PE CARE LE FOLOSEȘTI):
- `index.html` - Fișierul principal HTML
- `styles.css` - Toate stilurile CSS cu Work Sans
- `script.js` - Funcționalitatea JavaScript
- `README.md` - Documentația proiectului

### Fișiere de ignorat (NU LE FOLOSEȘTI):
Toate fișierele cu extensia `.tsx`, `.ts` și folderele `components/`, `styles/globals.css` sunt pentru React și nu sunt necesare pentru proiectul vanilla.

## Cum să folosești proiectul:

1. Copiază doar fișierele: `index.html`, `styles.css`, `script.js` în folderul tău local
2. Deschide `index.html` în browser
3. Adaugă propria imagine în loc de placeholder
4. Personalizează conținutul după nevoi

## Structura finală vanilla:
```
proiect-local/
├── index.html
├── styles.css 
├── script.js
└── README.md (opțional)
```

Atât! Nu ai nevoie de nimic altceva.
